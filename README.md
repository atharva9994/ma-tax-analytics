# MA DOR Tax Compliance Analytics

A data analytics tool for identifying non-compliant taxpayers and prioritizing audit selection for the Massachusetts Department of Revenue.

## Live App
https://ma-tax-analytics-cktuvk93bjrh99znn4rohc.streamlit.app/

## What's Inside

- **Streamlit Dashboard** — Interactive compliance tracking, audit risk scoring, and industry benchmarking
- **Analysis Notebook** — Full statistical analysis located in `analysis/tax_compliance_analysis.ipynb` including data cleaning, pattern discovery, chi-squared tests, z-score based audit selection, and recommendations

## Tech Stack
Python, Pandas, Plotly, Streamlit, SciPy, Seaborn, Matplotlib

## How to Run Locally
```
pip install -r requirements.txt
streamlit run App.py
```
